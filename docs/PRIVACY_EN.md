# YKS Preparation Privacy Policy

YKS Preparation uses no account, advertising, analytics, or user tracking. Topic progress, mock-exam results, favorites, and settings remain only on the user’s device and are never sent to a server. Android automatic cloud/device backup is disabled; migration uses the app’s explicit export/import flow. News and content updates only download public static files and contain no user data. Data leaves the device only when the user explicitly starts “Back up data,” which exports a JSON file to a destination selected by the user. This app is not an official ÖSYM or YÖK product.
