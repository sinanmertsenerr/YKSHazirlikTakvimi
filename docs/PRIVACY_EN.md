# YKS Preparation Privacy Policy

## Data collected

YKS Preparation does not use accounts, advertising, analytics, or user tracking. There is no developer-operated backend for user data. Topic progress, mock-exam results, favourites, and settings are stored in SQLite and MMKV on the device and are not sent by the app to a developer-operated server.

## Backups and data control

Android automatic cloud and device backup is disabled. Data is exported as JSON to a destination selected by the user only after the user explicitly starts “Back up data.” The user controls copies stored at external destinations; the app cannot later access or remotely delete those copies. On-device app data can be removed from Android settings or by uninstalling the app.

## Content and network requests

News, calendar, and content updates download public static files over HTTPS. Topic progress, exam results, favourites, and settings are not attached to these requests. GitHub Pages, the hosting provider, may process standard technical access logs such as IP address, request time, and browser/device information, as ordinary web servers do. These logs are not combined with in-app user data or used by the developer to build user profiles.

## Notifications

Reminders are scheduled locally on the device after the user enables them. The app does not send a push token to a developer-operated server and does not send personalised remote notification content. Notification permission is requested only when the user enables a notification feature.

Because of the notification infrastructure, the app package includes Google Firebase (Messaging and Installations) components; on first launch these components may create an anonymous installation identifier associated with Google. The app does not link this identifier to user data and does not send it to a developer-operated server. Details: <https://firebase.google.com/support/privacy>

## Children and young users

The app is educational and does not include accounts, advertising, behavioural profiling, or personal-data transfer to a developer-operated server. Parents and users can manage on-device data through Android settings.
